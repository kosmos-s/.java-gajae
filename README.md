# 계산기 앱 (Calculator App)

Java Swing을 사용하여 만든 GUI 계산기 애플리케이션입니다.

## 📋 주요 기능

- **기본 사칙연산**: 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/)
- **추가 연산**: 나머지(%), 제곱(x²)
- **괄호 지원**: 복잡한 수식 계산 가능
- **키보드 입력**: 마우스 클릭 외에도 키보드로 조작 가능
- **실시간 수식 표시**: 입력한 수식을 화면에 표시

## 🚀 실행 방법

### 필요 조건
- Java Development Kit (JDK) 8 이상

### 컴파일 및 실행

```bash
# 컴파일
javac snippet/CalculatorApp.java

# 실행
java snippet.CalculatorApp
```

또는 IDE(IntelliJ IDEA, Eclipse 등)에서 바로 실행 가능합니다.

## 🎮 사용법

### 마우스 조작
- 숫자 버튼(0-9)을 클릭하여 숫자 입력
- 연산자 버튼(+, -, *, /, %)을 클릭하여 연산 선택
- `=` 버튼으로 계산 실행
- `C` 버튼으로 전체 초기화
- `CE` 또는 `←` 버튼으로 마지막 문자 삭제
- `x²` 버튼으로 제곱 연산
- `(`, `)` 버튼으로 괄호 입력

### 키보드 조작
- **숫자 키**: 0-9
- **연산자 키**: +, -, *, /, %, (, )
- **Enter**: 계산 실행 (= 버튼과 동일)
- **Backspace**: 마지막 문자 삭제

### 수식 예제
```
7 + 3 * 2 = 13
(5 + 3) * 2 = 16
9 x² = 81
10 % 3 = 1
```

## 🛠️ 기술 스택

- **언어**: Java
- **GUI 프레임워크**: Swing
- **레이아웃**: BorderLayout, GridBagLayout
- **수식 평가**: Stack 기반 중위 표기법 파서

## 📂 프로젝트 구조

```
snippet/
└── CalculatorApp.java    # 메인 계산기 클래스
```

## 💡 구현 특징

1. **수식 평가 알고리즘**: Stack을 활용한 중위 표기법 수식 계산
2. **연산자 우선순위**: 제곱(^) > 곱셈/나눗셈/나머지 > 덧셈/뺄셈
3. **이벤트 처리**: ActionListener와 KeyListener를 통한 멀티 입력 방식 지원
4. **UI 디자인**: 어두운 테마(다크 모드) 적용

## 🐛 알려진 제한사항

- 연속된 연산자 입력 시 오류 가능 (예: 5++3)
- 매우 긴 소수점 결과는 과학적 표기법으로 표시됨
- 0으로 나누기 시 Error 표시
